# DigitalScout — MVP 0.1 (Vercel-ready)

Браузерный прототип поиска цифровых товаров. DigitalScout получает реальные карточки и цены через Plati.Market и GGsel. Для Playerok и FunPay пока нет прямого источника выдачи.

## Деплой на Vercel

### 1. Загрузить проект на GitHub

1. Распакуй архив.
2. Создай новый репозиторий на GitHub.
3. Загрузи в репозиторий все файлы и папки проекта, включая `static/`, `main.py`, `requirements.txt` и `vercel.json`.

### 2. Импортировать в Vercel

1. Открой https://vercel.com/ и войди через GitHub.
2. Нажми **Add New → Project**.
3. Выбери репозиторий DigitalScout и нажми **Import**.
4. Для этого проекта не задавай отдельную команду сборки или запуска: Vercel должен автоматически обнаружить FastAPI-приложение `app` в `main.py`.
5. Нажми **Deploy**.

После публикации открой домен, который выдаст Vercel. Проверь также адреса `/api/health` и `/api/search?q=Windows%2011%20Pro` на своём домене.

## Запуск локально в Windows

1. Установи Python 3.11 или новее.
2. Открой терминал в папке проекта.
3. Выполни:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
uvicorn main:app --reload
```

Если PowerShell не разрешает активацию виртуального окружения, выполни команды без активации:

```powershell
py -m pip install -r requirements.txt
py -m uvicorn main:app --reload
```

Открой http://127.0.0.1:8000.

## Как устроен деплой на Vercel

- `main.py` — единственная точка входа FastAPI; отдельное перенаправление всех адресов в `/api/index` не требуется.
- `vercel.json` — включает файлы интерфейса в сборку Python-функции.
- `static/` — HTML-страница, стили и JavaScript. Приложение отдаёт их по `/` и `/static/...`.

## Источники предложений

- Plati.Market: получение названий, цен в рублях и ссылок на объявления через поиск каталога.
- GGsel: разбор публичной страницы поиска; карточки отсортированы по цене.
- Playerok и FunPay: в интерфейсе помечены как не подключённые, пока нет проверенного прямого источника выдачи.
- Цены и наличие могут быстро меняться; перед покупкой проверь карточку на самой площадке. Демонстрационные товары и цены не используются.
- Документация Plati описывает API партнёрской программы и рекомендует регистрацию в Digiseller и создание API-ключа: https://www.plati.market/api/.

## Ограничения текущей версии

- Прямой поиск подключён для Plati.Market и GGsel. Playerok и FunPay пока отмечены в интерфейсе как неподключённые.
- Vercel Functions подходят для сайта и коротких API-запросов, но не для постоянно работающего парсера. Не хранить историю в локальных файлах/SQLite внутри функции: файловая система функции не является надёжным постоянным хранилищем.
- Для будущей версии с историей цен потребуется внешняя база данных (например, PostgreSQL/Supabase). Сбор данных по расписанию лучше вынести в отдельный worker/сервер и соблюдать правила доступа площадок.

## API

- `GET /api/health`
- `GET /api/search?q=Windows%2011%20Pro`
- Дополнительный параметр поиска: `source` (`all`, `Plati.Market` или `GGsel`).

## Структура

- `main.py` — FastAPI и получение живой выдачи Plati.Market и GGsel.
- `vercel.json` — включает файлы интерфейса в сборку Python-функции.
- `static/index.html` — интерфейс.
- `static/style.css` — оформление.
- `static/app.js` — запросы к API и отображение результатов.
- `requirements.txt` — Python-зависимости.
